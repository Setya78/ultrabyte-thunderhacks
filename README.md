# UltraByte

> Rules tell you what happened. UltraByte tells you why it matters.

Explainable alert triage for gaming investigators, covering fraud/AML and safer-play harm.
Every score breaks down into named factors with a reason and a source, and every investigator decision lands on an append-only audit trail.

**Built during ThunderHacks II, 14-16 Oct 2026 (Algoma University).** No code existed before the opening ceremony; see `BUILD-LOG.md` and commit history.

**Data:** 100% SYNTHETIC. No real players, transactions, or sponsor data.
